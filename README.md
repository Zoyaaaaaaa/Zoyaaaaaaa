## About

I'm an AI Engineer focused on taking LLM systems from prototype to production — not just experimenting with models, but engineering, deploying, and optimizing the systems around them: retrieval, memory, orchestration, latency, and reliability.

I currently work as an **AI Engineer**, building AI systems for real client and business use cases across multiple domains.

- 🏭 Production AI systems, not just prototypes — reliability, latency, and evaluation are part of the design, not an afterthought
- 🧩 RAG and hybrid retrieval architectures built around the shape of the data, not a fixed template
- 🤖 Multi-agent and agentic systems using LangGraph — orchestration, tool use, and memory
- 🧠 Long-context and conversational memory design — summary memory, rolling windows, context management
- 🌍 Comfortable working remotely and asynchronously with distributed teams and clients
